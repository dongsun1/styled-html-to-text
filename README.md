# styled-html-to-text

스타일이 붙은 HTML 을 React Native `<Text>` 트리가 받을 수 있는 **토큰 문자열**로 바꾼다.

```ts
sanitizeGuideHtml('<span style="color:#FF0000;font-weight:bold">필수</span>')
// → '{{BOLD_COLOR:#FF0000:필수}}'

sanitizeGuideHtml('<p>매장에 방문하세요</p><p>사진을 찍어주세요</p>')
// → '매장에 방문하세요\n사진을 찍어주세요'
```

## 왜 이게 필요했나

광고 가이드 문구를 외부 편집기에서 HTML 로 받아 모바일 앱에 그려야 했다.

HTML 을 그대로 렌더할 수는 없었다. React Native 에는 `innerHTML` 이 없고, 웹뷰를
띄우면 스크롤·폰트·터치가 앱 나머지와 따로 논다. 그래서 **태그는 전부 걷어내고
스타일만 토큰으로 남긴 뒤** 앱이 그 토큰을 읽어 `<Text>` 트리를 만든다.

문제는 **입력이 우리 통제 밖**이라는 점이다. 편집기가 어떤 마크업을 뱉을지 모르고,
사람이 손으로 붙여넣은 HTML 도 들어온다. 그래서 이 함수는 세 가지를 지킨다.

- 모르는 태그·속성이 와도 죽지 않는다
- `{{치환토큰}}` 은 건드리지 않는다 — 뒤에서 실제 값으로 바뀌기 때문에
- 무엇이 들어와도 `<Text>` 가 받을 수 있는 문자열만 돌려준다

## 토큰

| 입력 스타일 | 토큰 |
|---|---|
| `color` | `{{COLOR:색:내용}}` |
| `font-weight: bold`, `<strong>`, `<b>` | `{{BOLD:내용}}` |
| `font-size` | `{{SIZE:크기:내용}}` |
| 색 + 굵기 | `{{BOLD_COLOR:색:내용}}` |
| 색 + 크기 | `{{COLOR_SIZE:색:크기:내용}}` |
| 굵기 + 크기 | `{{BOLD_SIZE:크기:내용}}` |
| 셋 다 | `{{BOLD_COLOR_SIZE:색:크기:내용}}` |

중첩된 스타일을 위해 변환을 최대 3회 반복한다. 더 돌려도 바뀌는 게 없으면 멈춘다.

## 문서화해 둔 동작

테스트는 **실제 동작을 있는 그대로 고정**한 것이다. 바람직해 보이지 않는 결과도
그대로 적어 뒀다. 고치면 앱 쪽 렌더링이 같이 바뀌기 때문이다.

- **`<script>` 태그는 사라지지만 안쪽 글자는 본문으로 남는다.**
  결과물이 HTML 이 아니라 `<Text>` 로 들어가서 실행되지는 않지만,
  편집기에 붙여넣은 코드가 문구로 노출될 수는 있다.
- **이중 인코딩된 값이 한 번 더 풀린다.** `&amp;` 를 먼저 되돌리기 때문에
  `&amp;lt;` 가 `&lt;` 를 거쳐 `<` 까지 간다.
- **치환 토큰이 든 구간은 스타일을 입히지 않는다.** 토큰을 토큰으로 감싸면
  뒤쪽 파서의 non-greedy 정규식이 깨진다.
- **`<strong>` 안에 치환 토큰이 있으면 토큰만 남기고 나머지 글자만 굵게 한다.**
  `<strong>{{상품명}} 구매</strong>` → `{{상품명}}{{BOLD: 구매}}`

## 출처

리워드 광고 앱에서 쓰던 코드를 그대로 떼어냈다. 동작은 한 줄도 바꾸지 않았고,
`tsconfig` 도 원본 저장소와 같은 수준으로 맞췄다. 테스트도 원본 저장소에 있는
것을 그대로 옮겼다 — `import` 경로와 러너(Jest → Vitest)만 바꿨다.
